Cara Saya Bekerja

Saya tidak menampilkan nama client di sini, tetapi berikut adalah pola kerja dan jenis solusi yang biasa saya kerjakan.

Application Engineering

  • Mengembangkan aplikasi web operasional dan backend API untuk kebutuhan bisnis, administrasi, monitoring, dan pelaporan.
  • Merancang arsitektur multi-service dengan pemisahan app, database, cache, queue, scheduler, dan object storage.
  • Mengimplementasikan autentikasi, role-based access, session handling, dan API token untuk kebutuhan multi-user dan multi-platform.
  • Menghubungkan backend utama dengan service pendukung berbasis Node.js atau Go untuk automation, webhook, dan integrasi internal.

Deployment & Operations

  • Menyiapkan environment Docker dan Docker Compose untuk development, staging, dan deployment server.
  • Mengelola PostgreSQL, MySQL, Redis, dan object storage untuk transaksi aplikasi, cache, queue, serta file handling.
  • Menangani deployment di Linux server dan VPS, termasuk update code, build asset, dependency install, restart service, dan verifikasi pasca-deploy.
  • Mengelola environment virtualisasi berbasis Proxmox dan LXC untuk aplikasi, database, monitoring, dan object storage.

Monitoring & Reliability

  • Membangun monitoring server menggunakan Grafana, Prometheus, Node Exporter, dan smartctl_exporter.
  • Menangani backup, restore, migrasi storage, serta sinkronisasi object storage untuk menjaga ketersediaan data.
  • Menyusun akses remote multi-site menggunakan ZeroTier dan jump host agar lebih aman dan mudah dikelola.

Security & Growth

  • Menyiapkan monitoring keamanan server menggunakan Wazuh SIEM untuk meningkatkan visibility kondisi sistem.
  • Memiliki fondasi tambahan di cloud, security, dan data untuk mendukung pengembangan sistem yang lebih modern dan terukur.
  • Terbiasa bekerja di area backend, infrastruktur, cloud, security, dan data foundation secara bersamaan.
